# TVitality 医师诊断书 GUI — Phase 20

本阶段的医师 GUI 以用户提供的像素稿为唯一视觉基底，不重新设计布局。

## 已实现的界面约定

- 左侧纸张：诊断书。
- 第一行：`全部治疗`。
- 每个实际伤口占一行；同类伤口存在多份时逐份显示。
- 绿色勾由 GUI 绘制。
- 右上方黑色按钮：`确认治疗`。
- 右侧两行 × 五列：治疗费用提交槽位。
- 费用物品在选中伤口后显示在费用区域。
- 11 条为一页；超过 11 条时启用下一页，翻页后启用上一页。
- 玩家背包位于费用槽位下方。

## 测试

管理员可使用：

```text
/tv injury add tvitality:fracture
/tv injury add tvitality:cut
/tv doctor
```

注意：这些命令只是 Phase 20 的开发测试入口，不是最终医师 NPC 的交互方式。
